# 자동근태관리 v243 업데이트

[설치 파일 다운로드](./attendance_v243.zip?raw=true)

월별·개인별 소득세 및 지방소득세 명세, 월별/개인별 합계, 인쇄/PDF와 CSV 저장 기능을 추가한 업데이트입니다.

## 설치

1. 기존 자동근태관리 프로그램을 완전히 종료합니다.
2. ZIP 파일을 새 폴더에 압축 해제합니다.
3. `UPDATE_INSTALL.bat`를 실행합니다.
4. 기존 프로그램 폴더의 `retro_attendance.py`를 선택합니다.

기존 코드 파일은 백업하고, 기존 근태·급여 데이터베이스는 교체하지 않습니다.

## 사용

급여계산 → 세무보고 → 월별 · 개인별 소득세/지방소득세 출력에서 기간과 직원을 선택합니다.

이 자료는 세무보고 기초자료이며 홈택스 전자신고 업로드 서식이 아닙니다. 상여·퇴직소득 및 연말정산 세액은 별도로 확인해야 합니다.

회귀검증 7개 및 Linux 가상 화면의 창 생성·직원 선택·CSV/HTML 저장을 확인했습니다. 실제 Windows 설치 및 프린터 출력은 검증하지 않았습니다.
