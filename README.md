# 자동근태관리 v245 업데이트

[설치 파일 다운로드](./attendance_v245.zip?raw=true)

월별·개인별 소득세 및 지방소득세 명세, 월별/개인별 합계, 인쇄/PDF와 CSV 저장 기능을 추가한 업데이트입니다.

## 설치

1. 기존 자동근태관리 프로그램을 완전히 종료합니다.
2. ZIP 파일을 새 폴더에 압축 해제합니다.
3. `UPDATE_INSTALL.bat`를 실행합니다.
4. 기존 프로그램 폴더의 `retro_attendance.py`를 선택합니다.

기존 코드 파일은 백업하고, 기존 근태·급여 데이터베이스는 교체하지 않습니다.

## v245 추가 기능

- 월별 개인별 명세와 합계 표에 순번을 표시합니다.
- 세무보고 창에서 지급총액·과세급여를 각각 체크/해제할 수 있습니다.
- 선택은 화면, 인쇄/PDF, CSV의 명세와 합계 표에 동일하게 적용됩니다.

## v245 사원관리 개선

- Enter 및 숫자키패드 Enter로 자동 저장 후 다음 입력칸으로 이동합니다.
- 마지막 칸에서 저장하면 다음 사원의 사번 입력으로 이동합니다.
- 실제 생년월일(선택)에 `2004-04-22`처럼 입력하면 주민번호는 유지하면서 나이·정년·국민연금 계산에 우선 적용합니다.
- 생년월일은 확인한 실제 날짜만 입력하세요. 공란으로 저장하면 주민번호 기준으로 계산합니다.
- 기존 근태·급여 자료는 유지하고 생년월일 선택 항목을 위한 DB 열만 자동 추가합니다.

## 사용

급여계산 → 세무보고 → 월별 · 개인별 소득세/지방소득세 출력에서 기간과 직원을 선택합니다.

이 자료는 세무보고 기초자료이며 홈택스 전자신고 업로드 서식이 아닙니다. 상여·퇴직소득 및 연말정산 세액은 별도로 확인해야 합니다.

회귀검증 8개 및 Linux 가상 화면의 창 생성·직원 선택·CSV/HTML 저장을 확인했습니다. 실제 Windows 설치 및 프린터 출력은 검증하지 않았습니다.
